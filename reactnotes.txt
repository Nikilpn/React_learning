    jsx-javascript xml
    --------------------
    =>it is an js extension for writing html code,used in react to display contents in webpage
    =>jsx consists of jsx elements

    =>rules of jsx
    ---------------
    1.every jsx code must be inside a single tag,it can be a container tag / react fragment (<>  </>)
    2.every jsx must have a closing tag(starttag-content-endtag )/ self closing tag
    3.in jsx element attributes, style properties / values must be in a camel case
    4.in jsx ,attributes like "class" must be written as "className" and "for" as "htmlFor"
    5.in jsx,we can directly add js code using curly braces {}

    =>components
    -------------
    =>react is a collection of components .they are arranged in tree like structure .root node of react is app component
    =>components are used to create ui .it can be an entire web page or a part of webpage
    =>To create components,create a file with file name starts with capital letter and also component name must be same as file name 
    =>ways to create components
    -----------------------------
    1.functional based component/stateless components -react use pure function to build components and it must return jsx
    2.class based component/State full components   -use js class to build component,it must have render method where we can give jsx code.


    Events Haandling in React
    --------------------------
    =>Binding function without argument :use function-name only to call the function
    =>Binding function with argument    :call function using ()=>functionname(arg) 
    =>Binding function with argument as events :call function using (event)=>functionname(event)
    

                
    React props
    ----------
    =>used to share data from parent component to its child component .in react only parent component can share data to its child 
    =>props are properties of a component , props is an object so datas are stored as key value pair
    =>parent can share its data to its child tag using its attributes
    =>using "props" as child component function argument,using props we can access data in child  

    Conditional Rendering 
    ----------------------
    =>we can control visibility of jsx elements based on a condition ,using truthy or ternary operator.

    handling list in React
    ---------------------
    =>To display list in jsx  use "map"  array method .use key props to all duplicating jsx items in list ,key must be unique and used to identify by react dom.
    

    React state
    -----------
    =>state are used to store values in a component whenever state changes components also get rerender


    class based components                                   functional based components
    ---------------------------------------------------------------------------------------
    1.use js class to build components                      1.use js pure function
    2.statefull components                                  2.stateless components
    3.use constructor for initialising values               3.no need for constructor


    life cycle methods of components
    ---------------------------------
    3 phases

    1.mounting phase    :putting jsx content in to Dom
        ->constructor()
        ->getDerivedStateFromProps()
        ->render()
        ->componentDidMount()
    2.updating phase    :when component get updated
        ->getDerivedStateFromProps()
        ->shouldComponentUpdate()
        ->render()
        ->getSnapShotBeforeUpdate()
        ->componentDidMount()
    3.unmounting phase    :Removing component from Dom
        ->componentWillUnmount()

    React Hooks
    ------------
    =>React Hooks are predefined function for enabling react component features in functional components,all hooks name will start with "use" keyword
    =>how to use hooks in functional components
        ---------------------------------------
        ->import hooks in component
        ->call hook at top level component
    =>common hooks
    -----------------
        =>useState()  :used to create state in functional components
                      :useState(initialvalue)
                      const[setName,stateUpdateFunctionName]=useState(initialvalue)

        =>useEffect()   :used to add side effect to a component
                useEffect(effect,dependency)
                ->dependency can be in three ways:
                    1.no dependency :effect will apply all time in component
                    2.empty array  : effect will apply only at the creation of the component.
                    3.[variable_name, ....] :effect will apply not only at the creation of the component but also variable changes in component


        =>Hooks can be of two types
        ----------------------------
        1.predefined Hooks
                =>useState()  :used to create state in functional components
                      :useState(initialvalue)
                      const[setName,stateUpdateFunctionName]=useState(initialvalue)

                =>useEffect()   :used to add side effect to a component
                        useEffect(effect,dependency)
                        ->dependency can be in three ways:
                            1.no dependency :effect will apply all time in component
                            2.empty array  : effect will apply only at the creation of the component.
                            3.[variable_name, ....] :effect will apply not only at the creation of the component but also variable changes in component
                =>useRef() : used to store mutable data without rerendering the components .it also helps to get the reference of a html elements in to components

                    useRef(initiValue) :it returns object called current

        2.customised Hooks  :create a js file with name starts with "use" and inside the file define js function to complete task.
